# 🛒 E-Commerce Sales Dashboard

A dynamic and interactive **Power BI dashboard** built to track and analyze e-commerce sales performance across multiple dimensions including revenue, orders, payment methods, and referral sources.

---

## 📊 Dashboard Overview

This dashboard provides a comprehensive view of e-commerce business performance, enabling data-driven decision-making through clear visual storytelling.

### Key Metrics (KPIs)
| Metric | Value |
|---|---|
| 💰 Total Revenue | $1.26M |
| 📦 Total Orders | 1.20K |
| 🛍️ Total Quantity Sold | 4K |

---

## 📈 Visuals Included

### 1. Revenue Trend by Month
- Line/area chart tracking monthly revenue performance
- Peaks visible around **June–July** with revenue reaching ~$0.2M
- Helps identify seasonal trends and revenue dips

### 2. Orders by Month
- Bar chart showing order volume per month
- Highest orders in **July (147)**, lowest in **September (73)**
- Useful for capacity planning and marketing timing

### 3. State of Orders
- Horizontal bar chart showing order fulfillment breakdown:
  - Cancelled | Pending | Shipped | Returned | Delivered
- Helps monitor operational efficiency and return rates

### 4. Orders by Payment Method
- Pie/donut chart showing payment distribution:
  - Credit Card, Online, Cash, Gift Card, Debit Card
- Largest share: **Credit Card (20.86%)** and **Debit Card (20.74%)**

### 5. Referral Source
- Donut chart showing traffic/order sources:
  - Instagram, Email, Google, Facebook, Referral
- Top source: **Facebook (21.78%)**

## 🚀 How to Use

1. Clone or download this repository
2. Open `e-commerce_sales_dashboard.pbix` in **Power BI Desktop**
3. Refresh the data source if needed
4. Use the **Year slicer** to filter by 2023, 2024, or 2025
5. Interact with any visual to cross-filter the dashboard

---

## 💡 Key Insights

- Revenue peaked mid-year (June–July) and declined in Q4
- Order cancellations are notable — worth investigating root causes
- Instagram and Facebook are strong referral channels
- Payment methods are fairly evenly distributed across all types
